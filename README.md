# Almost Hero Android

Порт оригинальной Flash-игры на Android.

## Цель
Сохранить оригинальную механику, графику и звук, адаптировав управление под сенсорный экран.

## Этапы
1. Исследование SWF и игровой логики.
2. Документирование механик и ресурсов.
3. Выбор технологии переноса.
4. Реализация Android-версии.
5. Сборка APK и тестирование на устройстве.

## Текущий статус
Подготовительный этап: анализ оригинального SWF.
