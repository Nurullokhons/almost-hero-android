# Решения по концепции игры

Дата фиксации: 22.11.2026

## Цель проекта
Создать самостоятельную Android-игру по мотивам A.L.I.A.S. (оригинальной Flash-игры), используя её сюжетную атмосферу, образ героя и основные игровые действия как референс. Это не точная копия SWF и не перенос оригинального кода.

## Зафиксировано вместе с владельцем проекта
- Платформа: Android.
- Жанр: side-scrolling action / platform shooter.
- Камера: сбоку.
- Визуальный стиль: мультяшная 3D-графика; сохранить мультяшность оригинала.
- Герой: узнаваемый образ оригинального бойца, зелёный шлем и зелёная броня.
- Основные действия: бег, прыжок, перекат и стрельба.
- Подход к работе: ChatGPT разрабатывает код и материалы; GitHub хранит исходники и историю; владелец проекта участвует в принятии решений и тестирует сборки.

## Техническое направление
Предлагаемый движок: Godot 4. Он бесплатный, с открытым исходным кодом, поддерживает 3D-сцены, Android и автоматизированные сборки. Это предложение для реализации, а не уже подтверждённая установка или готовая сборка.

## Принцип разработки
Делать небольшие проверяемые этапы. Сначала минимальный игровой прототип с боковой камерой и движением героя, затем стрельба, противники, уровни, звук и сюжет. Не тратить время на полную декомпиляцию SWF; использовать оригинал как визуальный и игровой референс.

## Не решено
- Финальные пропорции героя.
- Детали управления на сенсорном экране.
- Сюжет и структура уровней новой игры.
- Минимальная версия Android и целевые устройства.
