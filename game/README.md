# Almost Hero - Godot prototype

This folder contains the first lightweight Godot 4 prototype for Android.

## Current prototype
- 3D scene with a fixed side camera.
- Procedurally built cartoon soldier in green armor and helmet.
- Simple walk-cycle animation for arms and legs.
- Ground collision, left/right movement and jumping.
- Basic projectile shooting.
- Compatibility renderer (OpenGL ES 3) for broad device support.
- No external art or large texture files yet.

## Temporary desktop controls
- A / Left Arrow: move left
- D / Right Arrow: move right
- Space / W / Up: jump
- Left mouse button or Ctrl: shoot

## Target test device
Realme C11 (2021), Android 11, 2 GB RAM.

## Next steps
1. Add touch controls for Android.
2. Add roll/dodge movement.
3. Build a small test corridor with simple platforms and obstacles.
4. Add enemies and health.
5. Prepare an Android debug build for device testing.

The hero is currently made from simple 3D shapes. This is an intentional temporary model to validate movement and performance before investing time in detailed art.
