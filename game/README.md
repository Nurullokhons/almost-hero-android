# Almost Hero - Godot prototype

This folder contains the first lightweight Godot 4 prototype for Android.

## Current prototype
- 3D scene with a fixed side camera.
- Simple capsule placeholder for the green-armored hero.
- Ground collision and basic left/right movement.
- Compatibility renderer (OpenGL ES 3) selected for broad device support.

## Temporary desktop controls
- A / Left Arrow: move left
- D / Right Arrow: move right
- Space / W / Up: jump (jump input is being refined in the next iteration)

## Target test device
Realme C11 (2021), Android 11, 2 GB RAM.

The capsule is only a temporary placeholder. The next iterations will add the stylized hero, touch controls, shooting, rolling, and optimized environment assets.
